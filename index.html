The Gameplay Loop

1. Customer enters through the green door → 2. Finds an open chair next to a table → 3. Orders food (see speech bubble) → 4. Cook takes the ticket to a stove → 5. Stove cooks (progress ring) → 6. Cook picks up the ready food and delivers it → 7. Customer eats, pays, leaves → 8. Dirty plate remains. A cook carries it to a sink → 9. Sink washes. Table reopens.

Traffic control

  • The Traffic bar in the sidebar scales customer spawn rate. At 1× customers arrive every 6 seconds; at 5× they arrive every 1.2 seconds. Crank it up to stress-test your kitchen.

Code layout

  • game.js — pure game logic. No Phaser. Tuning (CONFIG, FOODS), grid + A*, buildings, entities, the Simulation root.
  • sprites.js — all visual design. Iso geometry, color palettes, drawing primitives, and the Sprites object (one function per drawable).
  • scene.js — Phaser integration. Sidebar UI, GameScene orchestrator, and the Phaser.Game bootstrap.

Load order matters: game.js → sprites.js (needs COLS/ROWS) → scene.js (needs everything).
